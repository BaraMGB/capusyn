# Technische Entscheidungen

Hier werden wesentliche Architekturentscheidungen als Architecture Decision Records
(ADRs) dokumentiert, etwa Änderungen an Rendering, Threading, Parameteridentitäten,
Datenformaten oder Build-Abhängigkeiten.

**Status:** Ablage vorbereitet; noch keine Entscheidungen protokolliert.

## Konvention

- Dateiname: `0001-short-decision-title.md`, anschließend fortlaufend nummerieren.
- Inhalt: Status, Kontext, Entscheidung, betrachtete Alternativen und Konsequenzen.
- Status: vorgeschlagen, angenommen, verworfen oder durch ein anderes ADR ersetzt.
- Relevante Commits, Tests und Roadmap-Aufgaben verlinken.
- Angenommene Entscheidungen bei Richtungswechseln durch ein neues ADR ersetzen;
  die bisherige Begründung nachvollziehbar erhalten.

Eine Roadmap-Aufgabe ist noch keine angenommene Architekturentscheidung.
