# Dokumentationsabbildungen

Ablage für versionierte Diagramme und sonstige Abbildungen der technischen Dokumentation.

**Status:** Ablage vorbereitet; noch keine Abbildungen vorhanden.

- Aussagekräftige englische Dateinamen in `kebab-case` verwenden.
- Kleine Mermaid-Diagramme direkt in das zugehörige Markdown-Kapitel einbetten.
- Bei separat exportierten Diagrammen die bearbeitbare Quelle mit ablegen.
- Abbildungen aus den jeweiligen Fachkapiteln relativ verlinken.
- Keine persönlichen Daten, Zugangsdaten, Preset-Inhalte Dritter oder Build-Artefakte ablegen.
- Produktressourcen bleiben in `icons/`, `fonts/` und den übrigen Ressourcenverzeichnissen des Projekts.
